<h1 align="center">BotBus Issues</h1>

<p align="center">
  Found a bug, or have an idea? Tell us here.<br>
  This is the public place to report problems and suggest features for BotBus.
</p>

<p align="center">
  <a href="https://github.com/botbus-io/issues/issues/new"><strong>Open an issue</strong></a> ·
  <a href="https://github.com/botbus-io/issues/issues">Browse issues</a> ·
  <a href="https://botbus.io/en/">Website</a> ·
  <a href="#简体中文">简体中文</a>
</p>

## What goes here

- **Bugs** in any BotBus app: the menu bar app on your computer, the iPhone / iPad app, the Apple Watch app, or the Android app.
- **Agent problems**: a Codex, Claude Code or other agent session that doesn't show up, shows the wrong status, or doesn't respond to approvals, replies or interrupts.
- **Feature requests** and ideas for making BotBus better.
- **Questions** that the [website](https://botbus.io/en/) and its docs don't answer.

For problems with the protocol, the fixtures or the open-source connectors, use [botbus-protocol](https://github.com/botbus-io/botbus-protocol/issues) instead.

## Before you open an issue

1. **Search first.** Someone may have reported it already. If so, add a 👍 or your details to that issue instead of opening a new one.
2. **Update.** Check that you are on the latest version of each app. On the computer, open BotBus → Settings → About → Check for Updates.
3. **One issue per problem.** It's much easier to track and fix that way.

## What to include

For a bug, the more of these we get, the faster we can fix it:

- **What happened** and **what you expected** to happen.
- **Steps to reproduce**, as exactly as you can.
- **Versions**: the BotBus version on each device involved (computer, phone, watch).
- **Devices and systems**: e.g. macOS 26.1 on a MacBook Pro, iOS 26.1 on an iPhone 17, watchOS 26.1.
- **Which agent**: Codex, Claude Code or another one, and its version if you know it.
- **Screenshots or a screen recording**, if it's something you can see.

For a feature request, describe the problem you are trying to solve, not only the solution you have in mind.

## Keep your data private

Issues here are **public**. Please do not post:

- Pairing QR codes, pairing links, or anything that looks like a key or token.
- API keys, passwords or other credentials.
- Private code, file paths or conversation content you don't want the world to see. Crop or blur screenshots before uploading.

If we need something sensitive to investigate, we'll ask you to send it privately.

## Security vulnerabilities

Please **don't** report security vulnerabilities in public issues. Email [support@botbus.io](mailto:support@botbus.io) with the details instead, and we'll get back to you.

<h1 align="center">BotBus 问题反馈</h1>

<p align="center">
  遇到问题，或者有好点子？在这里告诉我们。<br>
  这是反馈 BotBus 问题、提功能建议的公开渠道。
</p>

<p align="center">
  <a href="https://github.com/botbus-io/issues/issues/new"><strong>提交反馈</strong></a> ·
  <a href="https://github.com/botbus-io/issues/issues">查看已有反馈</a> ·
  <a href="https://botbus.io/">官网</a> ·
  <a href="#botbus-issues">English</a>
</p>

## 可以反馈什么

- **各个 app 的问题**：电脑上的菜单栏 app、iPhone / iPad app、Apple Watch app、Android app。
- **Agent 相关的问题**：Codex、Claude Code 或其他 agent 的会话没有出现、状态不对，或者审批、回复、中断没有反应。
- **功能建议**，以及任何让 BotBus 更好用的想法。
- **使用问题**：[官网](https://botbus.io/)和文档里找不到答案的。

协议、fixtures 或开源连接器的问题，请到 [botbus-protocol](https://github.com/botbus-io/botbus-protocol/issues) 提交。

## 提交之前

1. **先搜一下。** 可能已经有人反馈过了。如果有，在那条下面点 👍 或补充你的情况，不用再开新的。
2. **先更新。** 确认每台设备上的 app 都是最新版。电脑上可以在 BotBus → 设置 → 关于 → 检查更新。
3. **一个问题一条。** 这样更方便跟进和修复。

## 请写清楚这些

反馈 bug 时，信息越全，修得越快：

- **发生了什么**，以及**你期望的结果**。
- **复现步骤**，越具体越好。
- **版本号**：涉及到的每台设备（电脑、手机、手表）上的 BotBus 版本。
- **设备和系统**：例如 MacBook Pro 上的 macOS 26.1、iPhone 17 上的 iOS 26.1、watchOS 26.1。
- **用的哪个 agent**：Codex、Claude Code 或其他，知道的话附上版本。
- **截图或录屏**，如果问题是能看到的。

提功能建议时，请说说你想解决什么问题，而不只是你设想的做法。

## 注意保护隐私

这里的反馈是**公开**的。请不要贴出：

- 配对二维码、配对链接，或任何像密钥、令牌的内容。
- API key、密码或其他凭据。
- 不想公开的代码、文件路径或对话内容。上传截图前请先裁剪或打码。

如果排查需要敏感信息，我们会请你私下发送。

## 安全漏洞

安全漏洞请**不要**在公开 issue 里提交，请把详情发邮件到 [support@botbus.io](mailto:support@botbus.io)，我们会尽快回复。
